# Manuscript figures

This directory contains the disclosure-reviewed figures used by the manuscript.

- `prenec_probability_tree.*` and `prenec_methodology_framework.*` are
  methodological diagrams. Their standalone LaTeX sources are tracked beside
  the compiled PDFs.
- `figure_joint_bootstrap_both_sexes.pdf` and
  `figure_joint_bootstrap_by_sex_supplementary.pdf` are generated by
  `scripts/12_make_joint_bootstrap_figures.R`.
- `figure_variance_decomposition_sample_a.pdf` is generated by
  `scripts/14_make_variance_decomposition_figure.R`.

The analytical figures contain only aggregate, publication-level estimates.
Their plotted values are provided in `../source_data/`.
Participant-level bootstrap records, simulation draws, and unrestricted local
results remain excluded from version control.
