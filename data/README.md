# Data directories

- `raw/`: eight original regional PRENEC workbooks. Restricted and ignored.
- `private/`: transformed patient-level and historical comparison files.
  Restricted and ignored.
- `derived/`: generated A/B datasets. Ignored pending disclosure review.
- `intermediate/`: the six released A/B products containing counts by age and
  sex, with no participant identifiers or dates.
- `parameters/`: deidentified literature-derived model parameters tracked for
  reproducibility.

Only placeholder files are committed in restricted directories.
